# Amal Projects

5 React Projects by Amal.

## 1. My Shop - `src`
Search products by name. iPhone, Samsung, Huawei, Nokia.
Shows products list and price in BD.

## 2. My Bill - `my-bill`
Calculate bill.
Enter name, number of shirts, price per shirt. Shows total bill.

## 3. My Orders - `my-orders`
Order Book. Add orders.
Enter name, item, price. Shows total orders and total money.

## 4. My Find - `my-find`
Find Customer. Add, Search and Delete orders.
Search by name. Delete wrong order.

## 5. My Paid - `my-paid`
Paid or Not Paid. Green = Paid, Red = Not Paid.
Shows Total, Paid, and To Collect money.
